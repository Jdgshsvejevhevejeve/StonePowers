# StonePowers SMP — Hearts Edition

Paper 1.21.11 / Java 21.

## Gameplay
- First join: random stone is assigned.
- Every player starts with 10 hearts.
- Player kill: killer gains 1 heart; victim loses 1 heart.
- Maximum: 20 hearts.
- Right-click the stone item to activate its ability.
- Killing a player also claims their Stone.
- `/stone hearts` shows your current hearts.
- Admin: `/stone giveall`, `/stone give`, `/stone reroll`, `/stone sethearts`, `/stone resethearts`, `/stone reload`.

## Build
Push to `main`. GitHub Actions automatically builds the plugin JAR and packages the resource pack.
